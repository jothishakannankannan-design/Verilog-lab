# OR Gate using Verilog HDL

## Description

The OR gate is a fundamental digital logic gate that performs the logical OR operation. It produces a HIGH (1) output when one or both of its inputs are HIGH (1). The output is LOW (0) only when both inputs are LOW (0). OR gates are widely used in digital electronics, FPGA designs, and various combinational logic circuits.
